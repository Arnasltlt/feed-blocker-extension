# Context routing

Read one domain `SUMMARY.md` next, then open the files it points to (under `extension/`, `server/`, or repo root).

| Folder | One-line role |
|--------|----------------|
| [`_config/`](_config/SUMMARY.md) | Stable constraints: deploy, env vars, dev setup pointers |
| [`_drafts/`](_drafts/SUMMARY.md) | Non-authoritative: samples, stale snapshots, scratch artifacts |
| [`extension/`](extension/SUMMARY.md) | Chrome extension: manifest, content scripts, popup, feed UI, background |
| [`server/`](server/SUMMARY.md) | Flask API: `/rerank`, `/summarize`, AI keys, Fly deployment |

**`_config/`** is for durable rules and pointers to canonical files. **`_drafts/`** is not authoritative for product behavior.
